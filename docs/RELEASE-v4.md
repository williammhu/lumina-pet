露米娜伴行 4.0：支持 Codex 状态联动、21 种动作、1280×1536 透明动画与 30 FPS 播放目标。

**安装：请下载 part1.zip 和 part2.zip 两份文件，并解压到同一个文件夹。** 两个 ZIP 合并后得到 `Lumina-Desktop`，双击里面的 `Lumina.exe`。不要单独移动 EXE 或缺少 `assets`。Windows 10/11 x64，需 .NET Framework 4.8。

此版本统一人物大小，修复施法和展翼时角色变小。支持自由缩放、拖动、鼠标穿透、隐藏脚边状态条与空闲随机动作。高清帧由既有素材升采样生成，非重新绘制的原生 1K 纹理。

两份 ZIP 合计约 3 GB。`SHA256SUMS.txt` 提供文件校验；下方的 Source code 仅供开发使用。
